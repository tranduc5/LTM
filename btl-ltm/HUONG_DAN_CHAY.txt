MULTI-ROOM CHAT SYSTEM - BAN NANG CAP
==================================
1) Giai nen ZIP, mo thu muc btl-ltm bang NetBeans (File -> Open Project).
2) May can Java 11+ va ket noi Internet lan dau de Maven tai SQLite JDBC.
3) Chuot phai project -> Clean and Build. Neu NetBeans chua tai dependency, chon Reload Project / Download Dependencies.
4) Run Project (F6). Truy cap http://localhost:8080.
5) Dang ky 2 tai khoan, moi tai khoan mat khau it nhat 8 ky tu, sau do dang nhap.
6) Tao phong, nhan ten nguoi trong cot 'Tin nhan rieng' de mo PM, nhan kep giay de gui file.
7) Du lieu luu o data/chat.db va uploads/ (duoc tao khi chay).
8) File gioi han 600 KB, cac dinh dang png/jpg/jpeg/gif/webp/pdf/txt/zip.
9) TCP client Java: dung REGISTER/LOGIN thay vi NICK. Web co UI thuan tien hon cho file.
